# مملكة الحيوانات (MVP محسّن)

نسخة محسّنة من لعبة سؤال/جواب تعليمية باللغة العربية.

ميزات التحسين التي أضفتها:
- فصل CSS وJS عن HTML لتسهيل الصيانة والتحميل.
- تصحيح شريط التقدم ليعكس التقدّم بشكل صحيح.
- إدارة أفضل للمؤقت (إيقاف عند الانتقال/إعادة التشغيل/الخروج).
- دعم وصول أفضل: عناصر قابلة للتركيز، دعم لوحة المفاتيح، aria-live للتغذية الراجعة.
- حفظ اسم اللاعب والنتائج البسيطة في localStorage لتحسين تجربة المستخدم.

التشغيل محلياً:
1. افتح `index.html` في متصفح حديث — لا حاجة لخادم.
2. أو انشر المجلد على GitHub Pages (Settings → Pages → Source → branch `main` / root) ليصبح متاحًا على الويب.

اقتراحات مستقبلية (للمستوى الاحترافي التعليمي):
- إضافة محتوى تعليمي موسّع لكل سؤال (روابط مصادر، صور، أصوات قصيرة).
- نظام تجميع أسئلة ديناميكي (JSON خارجي أو API) لسهولة التحديث.
- لوحة نتائج عامة وحماية ضد الغش.
- اختبارات وحدات لJS و linting في CI.

تم رفع الملفات إلى المستودع: `index.html`, `styles.css`, `app.js`, `README.md`.
